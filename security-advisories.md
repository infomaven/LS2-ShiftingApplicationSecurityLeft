# Security Advisories

Where to subscribe for security advisories for common platforms. This replaces
`LINKS - Security Advisories.pdf` (2019), which is kept only for historical reference.

_Last reviewed: October 2026._

> Tip: rather than following every feed manually, generate an SBOM for your application
> (e.g. with Syft or Trivy) and let a tool like OSV-Scanner, Dependabot, Renovate or
> OWASP Dependency-Track match it against advisories for you.
