# RESOURCES - LeftShiftSecurity-LS^2 is Shifting Application Security to the Left
Resources for my talk at SeaGL 2019 on Shift Left Security testing, refreshed in 2026 to reflect
current tooling and practices.

Primary audience is Devs, but this is really a pep talk for the entire team.

Emphasis is on Open Source and free versions of tools.

## Contents
- [resources.md](resources.md): curated tools, standards, education and practice targets
- [security-advisories.md](security-advisories.md): where to get security advisories by platform
- [whats-changed.md](whats-changed.md): how the ideas in the 2019 slides map to today's ecosystem
- `slides-min.pdf`: the original 2019 slide deck (historical)
- `LINKS - Security Advisories.pdf`: original 2019 advisories handout (superseded by `security-advisories.md`)

Do you know of a tool or resource that is not on here, or a link that has gone stale? Please fork
this repo and make a pull request.
